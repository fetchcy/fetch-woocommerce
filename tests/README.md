# Tests

- `php tests/unit.php` — webhook signature, order mapping rules, price markup maths, request batching, deactivation rows, masked customer details, the per-order import lock (on in-memory SQLite) and the "Mirror this shop 1:1" scan, plan, 50% guard and switch-off batches (against a fake API), no WordPress needed.
- `node tests/e2e/run.mjs` — boots WordPress Playground with WooCommerce and this plugin, points it at a local mock of the Fetch Partner API (`mock-fetch.mjs`), and runs the full flow: product sync, stock change, price markup resync, batches over 200 rows, delete/trash, order import, accept, status changes, masked customer details, webhook + poll races, signed/unsigned webhooks, and "Mirror this shop 1:1" (mode off, preview, switch-off of listings with no ref / a foreign ref / an excluded product, a product coming back, a failed scan page, a failed push, the over-50% guard and "Apply anyway", batches over 200 rows). The mock keeps the store's listings, pages `GET /listings` with `nextCursor`, and applies the live `listings/batch` rules. Needs internet the first time (downloads Playground + WooCommerce). Takes ~3–5 minutes.
