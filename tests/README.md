# Tests

- `php tests/unit.php` — webhook signature, order mapping rules, price markup maths, request batching, deactivation rows, masked customer details, the per-order import lock (on in-memory SQLite), the "Mirror this shop 1:1" scan, plan, 50% guard and switch-off batches (against a fake API), default-language-only sync with stubbed WPML filters and Polylang functions (originals vs translations, shared SKUs, variations, save and delete hooks, the mirror's kept set, order lookup, no plugin), and the product content sent to Fetch (brand detection and the "Brand attribute" setting, specs from global and local attributes, plain-text descriptions with paragraphs, Yoast / Rank Math SEO meta, the API size limits), no WordPress needed.
- `node tests/e2e/run.mjs` — boots WordPress Playground with WooCommerce and this plugin, points it at a local mock of the Fetch Partner API (`mock-fetch.mjs`), and runs the full flow: product sync, stock change, price markup resync, batches over 200 rows, delete/trash, order import, accept, status changes, masked customer details, webhook + poll races, signed/unsigned webhooks, and "Mirror this shop 1:1" (mode off, preview, switch-off of listings with no ref / a foreign ref / an excluded product, a product coming back, a failed scan page, a failed push, the over-50% guard and "Apply anyway", batches over 200 rows), and a multilingual shop on Polylang (installed in the Playground, activated near the end): only English products and variations are sent, a translation sharing the SKU does not overwrite the original, the preview in wp-admin with Polylang's language filter on Greek, mirror switch-off of listings from translations, order stock on the original, deleting translations, and the "Synced language" readout; then a product with a global "Brands" attribute, local and global specs, HTML descriptions and SEO meta, and the "Brand attribute" setting. The mock keeps the store's listings, pages `GET /listings` with `nextCursor`, and applies the live `listings/batch` rules. Needs internet the first time (downloads Playground + WooCommerce). Takes ~3–5 minutes.
